Hi, I'm joe, And today, On [Pwn Sift Blog](/blog) i would announcing the release of NetHydra—specifically NetHydra 1.1.0, codenamed "leopard." where in this release we made a lot of changes and Update including **Root user by default** However, you might be wondering why you are here (we are announcing these release here).

To answer it, you might need to [read this post](/blog/hello-world) but in short, as Maintainer of NetHydra i am decide to move every **My project** including `NetHydra` in to this Space (Pwn Sift). But... how about `NetHydra Page` ?, NetHydra Page would be still active for storing Documentation of NetHydra until we move every Documentation to `Pwn Sift`.

**Another question that might arise is:** _Why 1.1.0? Why not 2026.3?_

To be honest, we had intended to continue releasing `NetHydra` versions 2026.2 through 2026.4 (running until the end of 2026)
however, given the significant overhaul involved—and the high likelihood of package breakage—we have decided to discontinue the previous version. In other words, we **do not recommend** updating from NetHydra 2026.2 to this version using `APT`. let's jump to the Main Update (Root user by default). say hello to `root/toor`! 


## Root User By Default

in this update we(I'm) made decision to make `root` user by default You might consider this a foolish and rash decision in this modern era, and I (we) understand that; however, I (we) created NetHydra to serve my own needs and to suit my specific requirements. Besides, we (I) have never recommended using NetHydra as a `daily desktop OS`.

> NOTE: root user by default only for standard NetHydra Edition

## New tools

As with every NetHydra release, this update also introduces several new tools and package additions.
To complement and expand the scope of NetHydra.

- [Fluxion]() - is a security auditing and social-engineering research tool
- [ligolo-ng]() - An advanced, yet simple, tunneling/pivoting tool that uses a TUN interface
- [chisel]() - fast TCP/UDP tunnel, transported over HTTP, secured via SSH. with a single executable
- [Evilginx2]() - Standalone man-in-the-middle attack framework used for phishing

Also, we adding some `old` tools into NetHydra `ISO`, including cisco-auditing-tool (CAT), cisco-global-exploiter, cisco-torch, 0trace, unix-privesc-check and smtp-user-enum. because these tools still able to use.

## Get NetHydra

as we have say before, we do not recommend you to update NetHydra using `APT`, so please [Grab new ISO](https://pwnsift.github.io/get)

```
root@nh:~# cat /etc/os-release
PRETTY_NAME="NetHydra leopard"
NAME="NetHydra"
VERSION_ID="1.1.0"
VERSION="1.1.0"
VERSION_CODENAME=leopard
ID=nethydra
ID_LIKE=debian
HOME_URL="https://nethydra.github.io/"
SUPPORT_URL="https://nethydra.github.io/doc"
BUG_REPORT_URL="https://github.com/nethydra/nethydra/issues"
root@nh:~# 
```
